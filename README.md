# StudyOS 📚

A menu-driven study organizer written in Python. StudyOS keeps a student's
profile, subjects, tasks, notes, and marks in one simple command-line app.

## Features
- Student profile (name, age, course, subjects)
- Subject tracking (comma-separated subjects, split into a list)
- Task list: add and view tasks
- Notes: add and view notes
- Marks entry per subject
- Menu loop with 7 options

## How to run
```bash
python Study_os.py
```
Requires Python 3. No external libraries.

## Concepts used
- Dictionaries and lists
- `while` loops and `if/elif/else` branching
- f-strings and user input
- String splitting
